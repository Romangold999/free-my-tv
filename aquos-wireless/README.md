# AQUOS Wireless Hub

Отдельное Android-приложение для SHARP AQUOS / Android TV. Package ID: `io.romgold.aquoswireless`. Целевая проверка: Android 11 / ARM32.

## Функции первого прототипа
- Встроенная локальная веб-панель, открывается в браузере телефона.
- Сенсорная зона и кнопки навигации.
- Ввод текста в активное поле (требует включения Accessibility Service).
- Список установленных TV-приложений и их запуск.
- Передача фото/видео с телефона на ТВ по Wi‑Fi, временный кэш и открытие внешним просмотрщиком/плеером без постоянного сохранения.

## Ограничения и безопасность
Телефон и ТВ должны быть в одной локальной сети. Интернет не нужен. Для первого прототипа веб-сервер не защищён PIN-кодом: использовать только в доверенной домашней сети. Перед обычным использованием необходимо добавить PIN/QR-сопряжение. Управление жестами и вводом текста требуют добровольного включения Android Accessibility Service. Некоторые приложения могут не поддерживать внешнее управление.

Переданный медиафайл временно копируется в cache телевизора, чтобы штатный проигрыватель мог открыть его; он не помещается в постоянную медиатеку.

## Сборка
Из этой папки: `gradle assembleDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`.
